## 游戏程序改动说明

如果你想尝试自己调节某些相关数值（如物理引擎刻速率上限），可使用用户脚本定义 `GameConfig__setOverrides` 全局函数来覆写这些值。具体请自行阅读游戏的 JavaScript 代码开头部分。

### 界面

- 所有版本现在均会在结算界面显示关卡限时。
- 触屏设备增加进入全屏模式的按钮（页面左上角），可以全屏游玩。
  - fw1–6: 已人工测试确认单人触屏模式可全部等级 A 通关。
- 转场黑幕的淡入淡出时间均从 500ms 减少到 300ms。
- fw1–6: 修复了某些情况下操作过快会导致转场黑幕无法淡出消失的问题。
- 使用鼠标滚轮或捏合手势将关卡缩小到全局视角，继续游玩时游戏会被锁定在全局视角。要解除锁定，请手动将关卡放大到局部视角。
- 实现了在关卡表上添加隐藏连接线的能力。
  - 关卡表中，原关卡和修改版关卡的连接线就以这种方式实现。关卡明细页面中显示为蓝色半透明线。

### 游戏机制
  
- fw4: 修复了钻石形关卡结算时不考虑小钻石的问题。
  - 机制与原作保持一致：如果收集了大钻石但没有完全收集小钻石，等级为 C。
  - 注意 fw5–7 中机制与此不同，小钻石没有完全收集也会导致无法通关。
- fw1–6: 修复了高刷新率屏幕下鼓风机阻尼偏大，风力感觉明显更弱的问题。
  - 先前由于此问题无法通关从而被修改的关卡（1-3、1-51、5-C5），现在已被恢复原样。

### 关卡

- 编辑了关卡 1-64、2-1、3-1、3-2、4-1、4-2、5-L1、5-C1，将教程文本从 `tutorial_keyboard` 移至 `tutorial` 图层以修复教程文本在移动端缺失的问题。

### 声音
  
- 修复了镜子滑杆停止移动后仍然继续发出声音的问题。
  - 滑杆的声音机制改为基于位置，滑块每次跨越 1/27 的整数倍位置时会发出声音。
- 修复了计时按钮按住时持续不断地发出状态更新信号，导致滑动平台发出巨大噪音的问题。

### 兼容性
  
- 使用更加正确的方式适配了不同刷新率的屏幕。
  - 修复了整个游戏或者部分动画效果在高刷新率屏幕上变慢或变快的问题。
  - 原先游戏内硬编码的屏幕刷新率限制现在硬编码为无穷大。
  - 使物理引擎的刻速率独立于渲染，避免物理运算压力过大导致帧率不稳定，或者帧率过低导致物理引擎出现「穿模」。目前的默认配置下，物理引擎会在 50–100TPS 范围内跟随帧率自适应调节刻速度。
- 所有版本均采用统一且合理的游戏进程数据加载方式，游戏内现在应该不会再出现可见的「幽灵关卡」，关卡成绩也不会在关卡表变更后「张冠李戴」到错误的关卡上。
  - 加载时，圣殿根据 `id` 字段匹配，关卡根据 `_id` 字段匹配，存档中其他内容被忽略。

### 作弊选项

- 添加无敌版与关卡全开配置选项。
  - 默认为关闭状态，可通过关卡明细界面打开。
- fw6–7: 添加允许观看广告原地复活的配置选项。
  - 默认为关闭状态，可通过关卡明细界面打开。开启后可立即复活，没有广告。
  - 关闭状态下，完全不会显示广告复活按钮。

## 魔改指南（不完全）

如果你想要自己尝试修改游戏或添加关卡：

- 你可合理利用浏览器开发者工具以及其他自动化工具抓取游戏资源文件和关卡数据文件。获取到的内容仅限用于非商业的测试与教育用途，滥用后果自负！
- 编辑关卡文件的工具是 <a href="https://github.com/mapeditor/tiled" target="_blank">Tiled</a>。要使关卡能在编辑器能够正常展示，你可能需要<a href="https://github.com/yezhiyi9670/fireboy-and-watergirl-grabber/tree/main/tiled-atlasses" target="_blank">一些补充文件</a>。
- 游戏主页和「关卡明细」界面不是原游戏的一部分，而是一个额外 Web 应用，其中「关卡明细」界面在妥善配置后可充当关卡表编辑器。<a href="https://github.com/yezhiyi9670/fireboy-and-watergirl-homepage" target="_blank">这部分也是开源的</a>。
